# Historical CPU job templates

These four reference templates retain the original Slurm allocation directives
and launch layouts. Each now exits before launching a worker. They are not
current submission commands; use the scheduler-free CPU workflow in
[the reader guide](../../docs/START_HERE.md) and adapt allocations to the target
cluster when needed.

The free-deposit inference template specifies ten task processes. The associated
research drivers specify two fits and 50 paired evaluation runs. Allocation
ceilings are distinct from measured costs. See the
[reference-listing guide](../README.md) for provenance and execution boundaries.
