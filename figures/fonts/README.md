# Fonts for the editable paper figures

The SVG figures keep live text and use STIX Two Text and STIX Two Math.
The matching TTF files are supplied here for editing the SVGs in a vector
editor. PDFs embed the necessary font subsets; PNG previews need no fonts.
The methods-overview SVGs use system sans-serif fallbacks and need no font files.

STIX Two Text version 2.13 b171 and STIX Two Math version 2.12 b168a are the
production font versions recorded with the supplied artwork. These third-party
font files retain their SIL Open Font License 1.1 and original notices:
[Text licence](OFL-STIX-Two-Text.txt), [Math licence](OFL-STIX-Two-Math.txt).
They are separate from the repository's MIT-licensed original material.
See [checksums](manifest.json) for the exact supplied files.
